## Concept (TODO: confirm)
Horror delivery game. Players load a delivery van (the "Graveyard Express") at a warehouse start area, then drive
it down a forest road to deliver packages to houses.

## Observed: Start Area (`Workspace.StartArea`)
- `DeliveryChute`: loads boxes into the van (see Systems).
- `VanUpgradeStation`, `PersonalUpgradeStation`: upgrade terminals.
- `WarehouseLights`, `WarehouseDecor`: set dressing.
- Shop ids wired to ProximityPrompts: `VanUpgrades` (garage terminal), `PersonalUpgrades` (counter terminal),
  `Weapons` (gun rack), `Stamina` (vending machine), `Gear` (lockers).

## Observed: Delivery Van (`Workspace.DeliveryVan`)
- Model parts: Chassis, Body, Cab, CabDetail, CabInterior, Interior, Cameras, Seats (1 VehicleSeat + 1 Seat),
  Wheels, Cargo, Packages, Shelves, RearDoors, SlidingDoor, Steps, Lights, Details.
- Driven by `VanDrive` (server, builds welds/hinges/doors/seat prompts) and `StarterPlayer.StarterPlayerScripts.VanDriverClient`
  (client-side drive loop; the driver's client owns van physics for zero input lag).
- Collision groups: `VanBody`, `VanWheel` (wheels do not collide with the body or each other).
- Attributes read from the model: `Scale`, `DriveSign`, `SteerSign`. Set by the chute: `MaxCargoBoxes`, `CargoBoxes`.

## Observed: Map
- `Workspace.ForestRoadMap`: Road, Shoulder, Trees, Bushes, Rocks, Props, Extension, Grass (hand-built).
- `Workspace.Houses`: House_C, House_D, House_F, House_G, House_H, Farmhouse (+ an unnamed Model).

- Not procedural yet. If infinite generation is added, follow the Procedural Map Rule in CLAUDE.md.

## Systems
- **Delivery chute** (`ServerScriptService.DeliveryChute`): when the van's rear doors are open and the chute mouth is
  inside the cargo area, a box spawns every 1.2s up to 24. Landed boxes are welded to `Cargo.Floor` after 3s or
  destroyed if they missed. Status lamp: red = no van, orange = doors closed, green = loading, blue = full.
- **Shops** (`ServerScriptService.StartAreaShops`): triggering a `ShopPrompt` fires `ReplicatedStorage.Remotes.OpenShop`
  to that client with the ShopId. **The shop UI is not built yet** (no client listener).
- **Framework** (`ServerScriptService.Server`): Bootstrap, Core (ServiceList, Scheduler, Net), Services (DataService,
  MonetizationService, ReplicationService, AntiExploitService). Persistence via `ProfileStore`. Admin via `Cmdr`.
  Shared code in `ReplicatedStorage.Shared` (Loader, Enums, Types, Util, NetDefs, Config).
